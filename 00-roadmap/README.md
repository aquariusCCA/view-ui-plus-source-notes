# 00-roadmap

本目錄是整份 View UI Plus 源碼學習筆記的入口。

它不負責分析單一元件，也不存放 Vue、TypeScript 或工程化基礎知識；它負責回答三個問題：

- 先學什麼，再學什麼？
- 每個階段要產出哪些筆記？
- 如何判斷自己已經讀懂並可以進入下一階段？

## 教學筆記設計

| 筆記 | 用途 |
| --- | --- |
| [note-package-workflow.md](./note-package-workflow.md) | 定義筆記包的 `origin -> atomic -> formal notes` 資料流、目錄責任與 review 標準。 |
| [learning-path.md](./learning-path.md) | 定義整體學習路線，說明從源碼準備到企業封裝的完整順序。 |
| [source-reading-order.md](./source-reading-order.md) | 規劃 View UI Plus 源碼閱讀順序，避免一開始就陷入複雜元件細節。 |
| [stage-goals.md](./stage-goals.md) | 拆分學習階段、能力目標、輸出物與進入下一階段的檢查點。 |
| [progress-tracker.md](./progress-tracker.md) | 用表格追蹤每個目錄、主題與元件的閱讀進度。 |

## 建議使用方式

1. 先讀 `note-package-workflow.md`，理解筆記包的資料流與產出規則。
2. 再讀 `learning-path.md`，建立整體地圖。
3. 接著讀 `source-reading-order.md`，決定第一輪源碼閱讀順序。
4. 每完成一個階段，回到 `stage-goals.md` 檢查是否達標。
5. 實際閱讀過程中持續更新 `progress-tracker.md`。
