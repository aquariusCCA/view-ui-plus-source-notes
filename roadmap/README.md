# Roadmap

本目錄是 `View UI Plus` 源碼學習工作區的「導航層」。

它不負責存放完整筆記、不負責存放實作程式碼，也不負責存放 AI prompts，而是用來管理：

- 學習總目標
- 階段規劃
- 元件學習順序
- 學習進度
- 完整源碼系統地圖
- 非元件主題 roadmap
- 暫時不做但值得保留的 backlog

Repo 層級的目錄分工與使用原則，請見根目錄 `README.md`。

## 目錄結構

```text
roadmap/
  README.md

```

## Roadmap 設計原則

這份 roadmap 採用「主線 + 副線」設計。

```text
主線：元件仿寫
副線：元件庫工程化主題
```

主線用來推進實作，避免只整理筆記不動手。

副線用來保留完整視野，避免只看元件，卻漏掉樣式系統、插件系統、型別系統、建置發布流程等重要主題。
