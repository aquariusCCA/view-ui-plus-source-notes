# Learning Overview

本筆記用來整理 `View UI Plus` 源碼學習的整體目標與主線。

## 學習目標

這個學習工作區的核心目標不是單純整理漂亮筆記，而是透過源碼閱讀、元件仿寫、重構與二次封裝，真正理解一套 Vue 元件庫如何被設計、實作與維護。

主要能力目標：

- 建立 Vue 元件源碼閱讀能力
- 建立元件仿寫能力
- 理解元件 props、events、slots 的設計方式
- 理解元件樣式、狀態與互動邏輯
- 練習將共用邏輯抽取與重構
- 最後能面向公司業務場景做企業級二次封裝

## 學習主線

```text
View UI Plus 原始碼
  ↓
元件源碼閱讀
  ↓
元件仿寫
  ↓
累積共用邏輯
  ↓
重構練習
  ↓
企業級二次封裝
```

## 當前重點

目前不追求一次看完整套 View UI Plus。

當前重點是：

```text
先完成一批基礎元件仿寫
```

原因：

- 仿寫可以檢查自己是否真的理解源碼。
- 實作過後，才知道哪些邏輯值得抽取。
- 有一批元件經驗後，再談重構與企業封裝才不會空泛。

## 暫時不做的事

目前先不做：

- 不急著整理完整筆記系統
- 不急著研究所有元件
- 不急著進入企業級封裝
- 不急著抽象出大量共用工具
- 不追求每一篇筆記都很完整

## 學習判斷標準

每學一個元件，最重要的判斷標準是：

```text
我能不能不看原始碼，說明這個元件的設計？
我能不能自己做出一個簡化版？
我能不能知道哪些地方是元件庫常見設計？
```
