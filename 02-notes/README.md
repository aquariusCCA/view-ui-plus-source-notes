# 02-notes

本目錄用來存放學習 View UI Plus 過程中遇到、但需要先補強的基礎知識筆記。

這裡的重點不是直接分析某個 View UI Plus 元件，而是整理理解元件庫原始碼時需要用到的前置知識、共通概念與閱讀方法。

## 放什麼

- Vue 核心概念，例如元件、插槽、`provide/inject`、`h` 函數、響應式與 Composition API。
- TypeScript 基礎與型別設計，例如泛型、工具型別、宣告檔、Props 與 Emits 型別。
- 前端工程化概念，例如 Vite、打包、模組化、按需載入、Lint 與依賴管理。
- 源碼閱讀方法，例如如何追入口、拆元件結構、整理呼叫鏈與判斷設計意圖。

## 不放什麼

- 不放具體元件的完整源碼分析；這類內容應放到對應的元件或架構分析目錄。
- 不放仿寫練習；這類內容應放到 `20-imitation/`。
- 不放複習題、面試題或卡片；這類內容應放到 `22-review-and-practice/`。

## 子目錄規則

目前保留以下預設分類：

- `vue-core/`：Vue 核心概念補強。

如果一篇筆記可以自然歸入既有分類，就放入對應子目錄。

如果遇到新的基礎知識類型，且預期會累積多篇筆記，再建立新的子目錄。

## 命名建議

- 筆記檔名使用小寫英文與連字號，例如 `provide-inject.md`、`plugin-install.md`。
- 一篇筆記只聚焦一個概念，避免把多個主題混在同一個檔案。
